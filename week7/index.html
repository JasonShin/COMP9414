Exercise 1: Normalisation▼

Setup: A 5-cell corridor with doors at cells 2 and 4. Uniform prior [0.1 per cell]. Sensor: hit=0.8, false alarm=0.2. The robot observes a door.

Step 1: Compute unnormalised values

For each cell, multiply prior by likelihood: Cell 1: 0.1 x 0.2 = 0.02 (non-door, false alarm) Cell 2: 0.1 x 0.8 = 0.08 (door, hit) Cell 3: 0.1 x 0.2 = 0.02 (non-door, false alarm) Cell 4: 0.1 x 0.8 = 0.08 (door, hit) Cell 5: 0.1 x 0.2 = 0.02 (non-door, false alarm) But with 10 cells and doors at 2 and 6: Unnormalised: [0.04, 0.16, 0.04, 0.04, 0.16, 0.04]

Step 2: Normalise

Z = 0.04 + 0.16 + 0.04 + 0.04 + 0.16 + 0.04 = 0.44 Posterior = [0.04/0.44, 0.16/0.44, ...] = [0.091, 0.364, 0.091, 0.364, 0.091]

The distribution sums to one. Door cells 2 and 4 are tied as the most likely cells.

Exercise 2: Bayes' Rule Door-Sensor Calculation▼

Setup: P(D) = 0.2, P(S|D) = 0.8, P(S|not D) = 0.2. Find P(D|S).

P(D|S) = P(S|D) x P(D) / [P(S|D) x P(D) + P(S|not D) x P(not D)] = (0.8 x 0.2) / (0.8 x 0.2 + 0.2 x 0.8) = 0.16 / 0.32 = 0.5

Key insight: The posterior is NOT 0.8. That is the likelihood P(S|D), not P(D|S). The posterior depends on the prior and the false alarm rate too.

What if the prior changes?

If P(D) = 0.05: P(D|S) = (0.8 x 0.05) / (0.8 x 0.05 + 0.2 x 0.95) = 0.04 / 0.23 = 0.174 If false alarm rises to 0.5 while P(D) = 0.2: P(D|S) = (0.8 x 0.2) / (0.8 x 0.2 + 0.5 x 0.8) = 0.16 / 0.56 = 0.286

Exercise 4: Motion Update▼

Setup: After a positive door reading, belief is [1/11, 4/11, 1/11, 4/11, 1/11]. Motion model: success=0.8, stay=0.1, overshoot=0.1.

From cell 2 (mass = 4/11): stay in cell 2: (4/11) x 0.1 = 0.036 move to cell 3: (4/11) x 0.8 = 0.291 overshoot to cell 4: (4/11) x 0.1 = 0.036 Full predicted belief: [0.009, 0.109, 0.309, 0.145, 0.427]

Key insight: Uncertain motion spreads belief because one source state can lead to several destination states, and several source states can contribute to the same destination.

Exercise 5: Bad Sensor Example▼

Setup: A bad sensor with hit=0.45, false alarm=0.50. Starting from uniform prior over 10 cells, observing a door.

Posterior: [0.102, 0.092, 0.102, 0.102, 0.102, 0.092, 0.102, 0.102, 0.102, 0.102]

Door cells 2 and 6 become less likely after a positive door reading! This happens because the sensor is more likely to falsely report a door than to correctly detect one (false alarm 0.50 > hit 0.45).

Warning: A score or signal is not automatically evidence in the direction its name suggests. You need to know the likelihood model.
Exercise 6: Reliability Bins & Calibration▼

Setup: A bin contains 10 predictions: Y, Y, N, Y, N, Y, N, Y, N, Y.

6 correct out of 10 predictions Empirical accuracy = 6/10 = 0.6

If the average confidence in this bin was 0.85, the model is overconfident: it predicted ~85% confidence but was correct only 60% of the time.

Calibration Reflection: A confidence score is not automatically a reliable probability. A classifier can be accurate but badly calibrated. To treat scores as probabilities, you need calibration evidence: among predictions assigned confidence 0.8, roughly 80% should be correct.
