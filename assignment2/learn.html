Multi-Agent RL Concepts
4 marks · Policy gradient, actor-critic, PPO

Policy vs Value Function

  • Policy maps states to a probability distribution over actions — not a single action. PPO outputs probabilities for all 5 actions (IDLE, UP, DOWN, LEFT, RIGHT).
  • Value function estimates the expected cumulative future reward from a state. It's a prediction, not an observation.
Tutor trap: If you say "policy maps states to actions," they'll correct you. PPO uses a stochastic policy — it outputs a distribution and samples from it.

Why Actor-Critic?

Three approaches to learning, each with trade-offs:

  • Actor only (Monte Carlo PG): Must wait until episode ends for returns. High variance No bias
  • Critic only (e.g., DQN): Derives policy indirectly (argmax Q). Can't do stochastic policies or entropy bonus.
  • Actor-Critic (PPO): Critic provides baseline V(s), advantage A = return - V(s). Low variance Small bias
Key insight: The advantage centers the learning signal around zero. Positive A = "better than expected" → increase probability. Negative A = "worse than expected" → decrease probability.

The Three Components of PPO Loss

Ltotal = mean(Lclip) + c1 · mean(Lvalue) − c2 · mean(Sentropy)
  • L_clip: Trains the actor. Clipped surrogate objective ensures stable policy updates.
  • L_value: Trains the critic. Squared error between predicted V(s) and GAE return target R.
  • S_entropy: Prevents premature convergence. Without it, policy collapses to always picking one action → agent gets stuck.
Why the minus sign on entropy? We're minimizing L_total. Subtracting entropy means we penalize low-entropy (confident) distributions, which encourages the policy to stay exploratory.

Non-Stationarity in Multi-Agent RL

1 Agent 2 updates π2 Agent 3 updates π3 Each agent's updates change the "environment" for the others

When multiple agents learn simultaneously, each agent's policy changes make the environment non-stationary from every other agent's perspective. This breaks the standard RL assumption of a fixed MDP.

IPPO (Independent)

  • Each agent has its own actor AND critic
  • Both see only local observation oi
  • Doesn't explicitly address non-stationarity
  • Relies on PPO's clipping to absorb instability
  • Scalable Simple
  • Poor coordination

MAPPO (Centralized Critic)

  • Shared actor (with agent-ID input)
  • Centralized critic sees global state s
  • Directly addresses non-stationarity
  • Consistent advantage estimates across agents
  • Better coordination Stable
  • Needs global state
CTDE paradigm (MAPPO): Centralized Training with Decentralized Execution. During training, the critic uses global info. During inference, each agent acts using only its local observation — no communication needed.

IPPO Architecture

  • 3 separate actors, 3 separate critics
  • Actor input: local obs (12×12×5 = 720)
  • Critic input: local obs (720)
  • No parameter sharing at all
  • Each agent is fully independent

MAPPO Architecture

  • 1 shared actor, 1 shared critic
  • Actor input: local obs + one-hot agent ID (723)
  • Critic input: global state (12×12×15 = 2160)
  • All agents share the same networks
  • Agent ID lets shared actor behave differently per agent
Why flatten instead of CNN? The 12×12 grid is small enough that an MLP works well. CNNs would be warranted for larger observation spaces (e.g., 84×84 Atari frames) where spatial feature extraction matters more.

Why 5 Binary Channels?

Each channel is a 12×12 binary grid encoding one type of spatial information. This is much better than encoding everything in a single channel with magic numbers (e.g., 1=agent, 2=dirt, 3=fragile).

  • Ft (Fragile map): Where fragile objects are — agent must learn to avoid these (collision = -20, truncation)
  • Si (Self position): Where this agent currently is — a single 1 in the grid
  • Oi (Other agents): Where other agents are — needed to avoid collisions
  • Et (Explored area): Which cells have been visited — helps avoid redundant exploration
  • Di (Docking position): Agent's start/home position
MAPPO global state: The centralized critic concatenates all 3 agents' observations into a 12×12×15 tensor (5 channels × 3 agents). This gives it a complete picture of the world — every agent's position, what each has explored, etc.

Tutor question: "What would happen if you increased epsilon to 0.5?" Answer: The clipping range widens to [0.5, 1.5], allowing much larger policy updates per step. This could speed up learning initially but risks destabilizing training — the whole point of PPO is keeping updates small.

Loss Function — How Each Part Trains the Network

Why "min" in L_clip? The min takes the pessimistic (lower) bound. If the unclipped objective looks great but the clipped version is lower, we use the clipped version — we'd rather be cautious than over-optimize on a single batch of data.

Activation Functions in Your Network

  • ReLU (hidden layers): f(x) = max(0, x). Simple, fast, avoids vanishing gradient problem. Standard choice for hidden layers in deep RL.
  • Softmax (actor output): Converts raw logits into a valid probability distribution (sums to 1, all non-negative). Required because the policy must output action probabilities.
  • No activation (critic output): The critic outputs a raw scalar value — it can be any real number (positive or negative), so no activation is applied.
Common mistake: Don't confuse softmax with sigmoid. Sigmoid outputs independent probabilities per output (used for multi-label classification). Softmax ensures the outputs are mutually exclusive and sum to 1 — exactly what we need for choosing one of 5 actions.

Why Adam?

Adam (Adaptive Moment Estimation) combines two ideas:

  • Momentum: Uses a running average of past gradients to smooth out noisy updates (especially important in RL where gradient estimates are inherently noisy)
  • Adaptive learning rates: Each parameter gets its own effective learning rate based on the magnitude of its recent gradients. Parameters with consistently large gradients get smaller steps, and vice versa.

Compared to vanilla SGD, Adam converges faster and is less sensitive to the choice of learning rate — critical in RL where the data distribution is constantly shifting.

The 4 Evaluation Metrics

Episode length gotcha: It's averaged over successful episodes only. If no episodes succeed, report N/A. An episode "succeeds" when all dirt is cleaned before the 50-step time limit.

  • Expected: Higher success rate, lower episode length
  • Risk: Agents overfit — won't generalize

Random Mode

  • Agents must learn reactive policies
  • Tests: Can the agent generalize?
  • Expected: Lower success rate, but more robust behavior
Key discussion point: Does MAPPO's advantage over IPPO grow larger in random mode? If yes, it suggests the centralized critic helps more when coordination is harder (novel configurations the agents haven't memorized).

IPPO vs MAPPO — What to Expect & Why

Don't just state results — explain WHY. MAPPO converges faster because the centralized critic gives all agents a consistent, stable value estimate of the global state, reducing the non-stationarity that slows IPPO down.

Task Efficiency: Global RCR & RCR Heatmap

Global RCR = Σ revisit_map(x,y) / max(1, Σ visit_map(x,y))

RCR = Redundant Coverage Ratio. It measures what fraction of all cell visits were revisits (going to a cell that was already explored).

  • Low RCR = agents efficiently partition the grid, minimal overlap Good coordination
  • High RCR = agents keep revisiting the same cells Wasted effort

The per-cell RCR heatmap shows which specific grid cells have the most redundancy:

RCRMap(x,y) = revisit_map(x,y) / visit_map(x,y) (if visited, else 0)
What to say in discussion: "MAPPO achieves lower Global RCR because the centralized critic can evaluate the joint state — it learns that agents covering different areas leads to higher team return. IPPO agents lack this shared perspective, so they're more likely to redundantly explore the same regions."

Agent Contribution (Advantage Analysis)

Ai = r + γ V(s') − V(s)

The advantage estimate measures how much better the actual outcome was compared to what the critic predicted. Aggregating advantages per agent across episodes shows each agent's contribution to team success.

  • High mean advantage: Agent consistently takes actions that exceed expectations → strong contributor
  • Near-zero advantage: Agent performs about as expected → steady but not outstanding
  • Negative advantage: Agent consistently underperforms expectations → "lazy agent" problem
IPPO vs MAPPO difference: In MAPPO, advantages are computed from the centralized critic (global state), so they reflect each agent's contribution to the team. In IPPO, advantages are from local critics, so they only reflect individual perspective — less meaningful for team contribution analysis.

Behavioural Diversity: Jensen-Shannon Divergence

JS(P || Q) = ½ KL(P || M) + ½ KL(Q || M)  where M = ½(P + Q)
KL(P || M) = Σ P(a) log( P(a) / M(a) )

JSD measures how different two agents' policies are. It's symmetric (unlike KL divergence) and bounded between 0 and 1.

Your code computes a 3×3 pairwise JSD matrix for the 3 agents. Diagonal is always 0 (agent vs itself). The off-diagonal values show how different each pair's average policy is.

Nuance for discussion: High diversity isn't automatically bad, and low diversity isn't automatically good. Ideally you want complementary behavior — agents that are different in useful ways (e.g., each specializing in a region). MAPPO with a shared actor may produce low JSD (similar policies) but the agent-ID input can still let them specialize.

Emergent Behaviors to Discuss

The tutor will likely ask: "What interesting behaviors did you observe?" Be ready to discuss:

  • Zone splitting: Did agents learn to cover different parts of the grid? (Check RCR heatmap — low-overlap areas suggest implicit zone assignment)
  • Fragile object avoidance: Did safety violations decrease over training? Agents should learn that collisions yield -20 and truncation.
  • Lazy agent problem: Did any agent learn to idle while others do the work? (Check per-agent advantage — if one agent has consistently negative or zero advantage)
  • Path efficiency: Did agents learn direct paths to dirt, or do they wander? (Compare episode length in fixed vs random mode)
  • Collision avoidance between agents: Did inter-agent collisions decrease? Agents should learn the other-agent observation channel is important.
Tying it together: MAPPO's centralized critic helps with emergent coordination because it can evaluate the joint outcome of all agents' actions. IPPO agents must discover coordination purely through individual trial-and-error, which is harder but can sometimes produce more creative/diverse strategies.

The Big Picture: IPPO vs MAPPO Trade-offs

The CTDE insight: MAPPO gets the best of both worlds — it uses global information to train better policies, but at execution time each agent acts independently using only local observations. The centralized critic is discarded after training.
