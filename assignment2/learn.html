Policy vs Value Function

  • Policy maps states to a probability distribution over actions — not a single action. PPO outputs probabilities for all 5 actions (IDLE, UP, DOWN, LEFT, RIGHT).
  • Value function estimates the expected cumulative future reward from a state. It's a prediction, not an observation.
Tutor trap: If you say "policy maps states to actions," they'll correct you. PPO uses a stochastic policy — it outputs a distribution and samples from it.

Why Actor-Critic?

Three approaches to learning, each with trade-offs:

  • Actor only (Monte Carlo PG): Must wait until episode ends for returns. High variance No bias
  • Critic only (e.g., DQN): Derives policy indirectly (argmax Q). Can't do stochastic policies or entropy bonus.
  • Actor-Critic (PPO): Critic provides baseline V(s), advantage A = return - V(s). Low variance Small bias
Key insight: The advantage centers the learning signal around zero. Positive A = "better than expected" → increase probability. Negative A = "worse than expected" → decrease probability.

  • Vanilla PG: No constraint on update size → policy can collapse with one bad update
  • TRPO: Hard KL-divergence constraint keeps policy close → but needs expensive 2nd-order optimization (Fisher matrix)
  • PPO: Same goal (small updates) achieved with simple clipping → only 1st-order methods needed (Adam)

The Three Components of PPO Loss

Ltotal = mean(Lclip) + c1 · mean(Lvalue) − c2 · mean(Sentropy)
  • L_clip: Trains the actor. Clipped surrogate objective ensures stable policy updates.
  • L_value: Trains the critic. Squared error between predicted V(s) and GAE return target R.
  • S_entropy: Prevents premature convergence. Without it, policy collapses to always picking one action → agent gets stuck.
Why the minus sign on entropy? We're minimizing L_total. Subtracting entropy means we penalize low-entropy (confident) distributions, which encourages the policy to stay exploratory.

Non-Stationarity in Multi-Agent RL

1 Agent 2 updates π2 Agent 3 updates π3 Each agent's updates change the "environment" for the others

When multiple agents learn simultaneously, each agent's policy changes make the environment non-stationary from every other agent's perspective. This breaks the standard RL assumption of a fixed MDP.

IPPO (Independent)

  • Each agent has its own actor AND critic
  • Both see only local observation oi
  • Doesn't explicitly address non-stationarity
  • Relies on PPO's clipping to absorb instability
  • Scalable Simple
  • Poor coordination

MAPPO (Centralized Critic)

  • Shared actor (with agent-ID input)
  • Centralized critic sees global state s
  • Directly addresses non-stationarity
  • Consistent advantage estimates across agents
  • Better coordination Stable
  • Needs global state
CTDE paradigm (MAPPO): Centralized Training with Decentralized Execution. During training, the critic uses global info. During inference, each agent acts using only its local observation — no communication needed.
