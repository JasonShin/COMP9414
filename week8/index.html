Exercise 3.1: Image Representation with OpenCV▼

Tasks:

  • 3.1.1-3.1.2: Read an image as both coloured (BGR) and gray-scale. Print shapes and pixel values.
  • 3.1.3: Save a copy of the gray-scale image as parrots_gray_test.jpg.
  • 3.1.4: Add a 75-pixel white border (frame) by setting border pixels to 255.
  • 3.1.5: Generate a random noise matrix with values in [0, 50] matching image dimensions.
  • 3.1.6: Add noise to the gray-scale image using cv2.add() (saturates at 255).
import cv2 import numpy as np # Read colour (BGR) and gray-scale img_colour = cv2.imread('parrots.jpg') # shape: (H, W, 3) img_gray = cv2.imread('parrots.jpg', 0) # shape: (H, W) # Save gray-scale copy cv2.imwrite('parrots_gray_test.jpg', img_gray) # Add 75px white frame frame = img_colour.copy() frame[:75, :] = 255 # top frame[-75:, :] = 255 # bottom frame[:, :75] = 255 # left frame[:, -75:] = 255 # right # Generate and add noise H, W = img_gray.shape noise = np.random.randint(0, 51, (H, W), dtype=np.uint8) noisy = cv2.add(img_gray, noise) # saturates at 255

Key Insight: OpenCV uses BGR channel order (not RGB). The shape of a colour image is (height, width, 3) while gray-scale is (height, width). Use cv2.add() instead of + to prevent overflow wrapping (values stay capped at 255).

Exercise 3.2: Noise Removal with Mean and Median Filters▼

3.2.1 Mean Filter: Replace each pixel with the average of its neighbourhood.

def mean_filter(image, window=3): img = image.copy() height, width = image.shape pad = window // 2 for i in range(pad, height - pad): for j in range(pad, width - pad): neighbourhood = image[i-pad:i+pad+1, j-pad:j+pad+1] img[i, j] = np.mean(neighbourhood) return img

3.2.2 Median Filter: Replace each pixel with the median of its neighbourhood (nonlinear, better at preserving edges).

def median_filter(image, window=3): img = image.copy() height, width = image.shape pad = window // 2 for i in range(pad, height - pad): for j in range(pad, width - pad): neighbourhood = image[i-pad:i+pad+1, j-pad:j+pad+1] img[i, j] = np.median(neighbourhood) return img

3.2.3 OpenCV Built-in Filters:

# Mean filter (box blur) cv2.blur(noisy_img, (3, 3)) # Median filter cv2.medianBlur(noisy_img, 3)

Pros of built-in: Much faster (C++ optimised), handles borders automatically. Cons: Less control, harder to understand what's happening internally.

3.2.4 Effect of kernel size:

  • 3x3: Removes less noise but preserves detail and edges
  • 5x5: Good balance between noise removal and detail
  • 7x7, 9x9: Removes more noise but blurs edges and fine detail
  • For typical noise levels, 3x3 or 5x5 is the sweet spot, especially with the median filter

Why use np.mean() instead of summing uint8 values? Summing uint8 values directly (e.g., image[i-1,j-1] + image[i,j-1] + ...) can overflow since uint8 max is 255. Using np.mean() computes in float internally, avoiding overflow.

Exercise 4.1: Edge Detection with Canny Filter▼

4.1.1: Load a video, print FPS, total frames, and duration. Display frame 1002.

video = cv2.VideoCapture('tom_and_jerry.mp4') fps = video.get(cv2.CAP_PROP_FPS) total_frames = int(video.get(cv2.CAP_PROP_FRAME_COUNT)) duration = total_frames / fps video.set(cv2.CAP_PROP_POS_FRAMES, 1002) ret, frame = video.read()

4.1.2: Apply Canny edge detection to each frame of the video.

gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY) edges = cv2.Canny(gray, lower_threshold=100, upper_threshold=200)

4.1.3: Effect of Canny thresholds:

  • Low thresholds (30/100): More edges detected, including noise and texture
  • Medium thresholds (100/200): Balanced -- main edges detected, noise rejected
  • High thresholds (200/400): Only the strongest edges survive

Canny uses two thresholds: pixels with gradient above the upper threshold are strong edges; pixels between lower and upper are kept only if connected to a strong edge; below lower is discarded (hysteresis thresholding).

Exercise 5.1: Transfer Learning with VGG16 on MNIST▼

5.1.2-5.1.3: Preprocessing MNIST for VGG16

MNIST images are 28x28 grayscale, values 0-255. VGG16 expects 32x32x3 with normalised inputs.

Preprocessing Pipeline: Step 1: Normalise pixel values -- divide by 255 (range 0-255 -> 0-1) Step 2: Resize 28x28 -> 32x32 and convert grayscale -> 3-channel (RGB) Why divide by 255? - Neural networks train better with small input values - Gradient updates are more stable - Prevents large activations that can cause exploding gradients

5.1.4: VGG16 Model Summary

  • VGG16 has 16 weight layers (13 conv + 3 fully connected)
  • Uses 3x3 convolution kernels throughout
  • Has ~138 million parameters in the full model
  • When using include_top=False, only the convolutional base is loaded (no FC layers)
  • Set base_model.trainable = False to freeze pre-trained weights

5.1.5: Adding Custom Classification Layers

model = models.Sequential([ base_model, # Frozen VGG16 convolutional base layers.Flatten(), # Flatten feature maps to 1D layers.Dense(50, activation='relu'), # Hidden layer 1 layers.Dense(20, activation='relu'), # Hidden layer 2 layers.Dense(10, activation='softmax') # Output: 10 digit classes ]) model.compile( optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'] )

# Preprocess: normalise, resize, add batch dimension image = train_ds[10] / 255.0 image = cv2.resize(image, (32, 32)) image = np.stack([image]*3, axis=-1) # grayscale -> 3 channels input_image = np.expand_dims(image, 0) # add batch dimension predicted_label = model.predict(input_image) predicted_class = np.argmax(predicted_label) actual_class = np.argmax(train_labels[10])
